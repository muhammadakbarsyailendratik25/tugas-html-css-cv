Subjudul Kecil dengan Renggang Karakter

Ini adalah contoh paragraf yang menerapkan text-indent: 2em. Baris paling pertama pada paragraf ini akan menjorok masuk ke dalam sejauh 2em (setara 32px), menciptakan tampilan khas penulisan buku atau artikel formal. penggunaan line-height: 1.6 memastikan jarak antarbaris memiliki cukup ruang bernapas agar pembaca tidak cepat lelah.

Paragraf ini menggunakan white-space: break-spaces, sehingga spasi berganda dan perpindahan baris di HTML akan ditampilkan sesuai bentuk aslinya.
